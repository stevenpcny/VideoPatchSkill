# 跨助手执行入口

请读取本目录的 [SKILL.md](SKILL.md)，把它作为这项 Flow 视频局部修补任务的操作指南。保持文件夹结构，参数/依赖/案例均通过相对链接提供。

先理解用户要修哪个人、哪段时间、是否保留原嘴和最终输出要求。读取媒体后按实例填写JSON，不照搬示例坐标。执行脚本前先 `doctor` 和 `--dry-run`，先做短片确认再处理完整片。

若你没有终端或文件读取权限，请说明可以提供的方案/参数，并让使用者在具备本地工具的环境执行；不声称已运行。若你有执行工具，直接使用本包Python脚本，无需桌面客户端。

素材准备、Flow生成、时间对齐、空间配准、合成、自动校验、视觉审看是不同状态。只报告实际完成的状态。不会自动上传素材、替使用者登录或消费额度。

当文字步骤足够表达目标时，不需要专有的 Codex API。脚本是普通命令行工具，Python输出和JSON报告可以交给任意助手继续处理。
