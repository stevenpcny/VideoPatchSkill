# 跨助手执行入口

请读取本目录的 [SKILL.md](SKILL.md)，把它作为这项 Flow 视频局部修补任务的操作指南。保持文件夹结构，参数/依赖/案例均通过相对链接提供。下面只列不可省略的几条，细节都在 SKILL.md。

- **白名单**：只用 SKILL.md 列出的工具；清单外先停止，核查并经当前用户明确批准才能用，不自动安装或换工具。首次在某台机器使用或版本变化时读 [工具白名单与审批](references/tool-policy.md)。
- **流程**：每台机器先 `doctor` 一次；调参时用 `merge --frames 关键区间 --preview` 检查（不改帧号、快速编码、报告标为不可交付）；参数定下来再做完整导出。不需要单独的 `--dry-run` 或手工裁短片。
- **状态如实报告**：素材准备、Flow生成、时间对齐、空间配准、合成、自动校验、视觉审看是不同状态，只报告实际完成的。不会自动上传素材、替使用者登录或消费额度。没有终端或文件权限时只给方案和参数，不声称已运行。
- **合成前预检**：收到返回片先跑 `qc_tools.py precheck`，再补人工项，给出"可贴／费劲／建议重刷"；接缝不放在脸上。
- **精简输出与记录**：QC 命令和 dry-run 用 `--brief`，需要逐帧数据再用 `--json-out`；merge 配置用 `init-merge` 从 prepare 报告生成，验收记录用 `qc_tools.py review-set` 写入，不手改 JSON。
- **视觉验收**：完整导出会生成预填的 `*.visual-review.json`；最终编码文件须做全修补帧巡检、放大边缘/背景/遮罩检查、接点重影检查及正常速度播放。未做或仍有接缝、重影、色偏时只能标为视觉待审/未通过，不能凭解码成功称"无接缝、无重影"。

多人交界或局部借用、可编辑达芬奇工程等专题，按 SKILL.md 的入口读对应指南。脚本是普通命令行工具，输出和 JSON 报告可交给任意助手继续处理。
