# 方案选择与通用示例

以下均为假设示例，不对应真实项目、人物或生成结果。数字只说明参数语义，不能作为新素材的实测配置。

| 目标或问题 | 选择 | 需要检查 |
|---|---|---|
| 只修眉眼，原嘴可用 | 上半脸遮挡与alpha贴回 | 羽化与保护区域覆盖全部嘴部运动 |
| 整脸或整头变化 | 容纳新旧轮廓的连续区域 | 头发、耳侧、下颌、遮挡与边缘 |
| 下颌和颈部接缝明显 | 对比宽柔边alpha与多频段融合 | 低频颜色、衣领及背景过渡 |
| 人物在画面移动 | 人工核对裁切关键帧或逐帧框 | 快速动作、转头和裁切边界 |
| 多人同时修补 | 分别生成，从同一原片一次合成 | 同帧区域交叉及前后遮挡 |
| 换人后脖子、手肤色不符 | 接缝改动量驱动的本地调色，或扩大生成区 | 接缝色差、衣服未被调色、全片一组参数 |
| 新发型体积大于原发型 | 该人单独扩大生成范围与蒙块外扩 | 头发边缘、背景与相邻人物 |

## 示例一 保留原嘴

先根据实际视频定义需要修补的上半脸范围，选择alpha融合；matte区域尽量远离嘴，protect覆盖嘴部全部运动。生成提示词中的保护要求不能代替合成时保护。参考`assets/upper-face-template.json`，所有坐标需重新测量。

## 示例二 返回帧数不同

假设目标区间有6帧，生成结果仅有5帧。在独立核对前五帧同序、并确认尾部允许短暂停留后，可显式使用`frame_map=[0,1,2,3,4,4]`；若选择保留最后一帧原画面则为`[0,1,2,3,4,null]`。两者均可能产生可见接点，必须播放检查。此示例不是自动补帧许可，也不适合中间缺帧时直接套用。

## 示例三 多人或多段

每个人或每段分别配置patch，使用通用名称`person-a`、`person-b`和相对媒体路径。同帧crop不能相交；复杂遮挡需另外设计细遮罩和层次。分段核心使用相邻但不重叠的`[a,b)`、`[b,c)`，上下文参照可以重叠。

## 连续整头区域与融合选择

若小范围贴回在下颌或脖子处反复出现接缝，可试连续整头到肩领区域，把过渡移向稳定背景或衣服，并对比alpha与multiband。这会扩大采用生成画面的范围，可能包含嘴、话筒和衣领，须先符合修补目标；必须保留原嘴时使用上半脸路线。多频段并不保证mask=1处所有频段完全来自生成画面。

## 局部修补的补充决策

眼周与镜框、扶镜手和衣袖交界、多人按人选优、短叠化比较、减少重编码、颜色转换及音轨尾包问题见 [局部补丁经验](patch-lessons.md)。该文区分实用方法与基础脚本能力，不直接套用历史参数。只修眼睛时先比较眼周局部和整体裁切覆盖的影响；后者包含生成的嘴、衣服与背景，必须明确范围。

## 案例原则：背景接缝与肤色不一致

人物裁切中的生成背景可能比原片更平滑、偏亮或偏色。即使头部已对齐，矩形柔边仍可能留下亮度圈、纹理块或随运动显露的边界。先分别查看原片、生成片、最终成片和黑白遮罩，再比较：缩小背景参与范围、原/新人物轮廓并集、连续头颈区域及多频段融合。扩大羽化不保证有效；不能为消除边界把原嘴/新嘴或新旧鼻尖混在一起。

颜色或亮度分离适用于人物与背景可分辨的具体镜头。深色头发和衣服与墙面暗纹可能同时落入“暗像素”条件，必须用实际样本比较，检查背景误选、亮发丝漏选、耳侧/下颌缺口及遮罩闪烁。不能把某次绿色墙面的阈值复制到复杂背景、遮挡或不同灯光中；需要清单外分割/跟踪工具时，仍按工具审批流程处理。现有主脚本只提供几何遮罩，不把此案例称为它已具备自动人物分割。

肤色检查包含脸、耳朵、脖子、手及跨段接点。温和的皮肤局部调整可减少“脸暖、脖子青”或背景染色；颜色权重也可能误选嘴唇、衣服或背景，须审看。参考图作为色彩方向，保留场景光照差异，不硬匹配不同曝光下的RGB，也不凭单一平均色宣称视觉一致。修改色彩矩阵/范围后比较实际解码画面，不能只补标签而不确认像素解释。

## 高级合成故障分流

| 现象 | 先区分 | 处理方向 |
|---|---|---|
| 旧眼镜/五官淡淡透出 | 核心alpha不足、错位或时间混帧 | 测实际透明度，再查映射及覆盖 |
| 发际线外随头移动的暗圈 | 遮罩边缘或低频参照带回旧头阴影 | 隔离原头空间光影，不能只加宽羽化 |
| 返回片较短 | 固定偏移、整段时间压缩或真实缺帧 | 首中尾动作核对后显式映射 |
| 脸比邻人更硬或更软 | 像素尺寸、对焦、过锐或生成细节不足 | 同场景小幅局部候选对照 |
| 仅特定播放器高位深偏色 | 像素解释、色彩信息或编码播放路径 | 实际播放器控制对照，变编码器仍须审批 |

详细诊断、反例及六组合成回归见[高级合成](advanced-compositing.md)。这些方法不代表主脚本已支持高位深或自动检测，亦不提供适用所有镜头的参数。

## 模板与共享

`assets/merge-template.json`提供多频段矩形配置结构，`assets/upper-face-template.json`提供保留嘴的alpha配置结构。尺寸与坐标仅为演示。分享实际配置时删除人物实名、真实项目名及可追溯描述，把媒体路径改成通用相对路径，不附真实素材和运行报告。
