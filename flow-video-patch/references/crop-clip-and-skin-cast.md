# 裁切小片段与肤色偏差

来自观众席刷口型任务（1080p、24 fps、固定机位、前后几排小头人物），已抽象；数值只说明量级。首帧、`context_frames` 与高清底图的通用规则见[实片经验二](hd-relay-lessons.md)，这里只补充本类任务特有的部分。

## 1. 认人与定框

- **标号截图的取景可能和视频不同**（截自另一版底图或缩放过）。不按截图坐标换算，按长相、衣服在视频帧里认人，或多尺度模板匹配（`cv2.matchTemplate`，缩放 0.5–3 步进 0.02，相关系数 >0.9 才采信）。
- 用户回传的小截图若截自你发的预览图，会带上框线；直接在带框的预览图上匹配，定位最准。
- **取景**：锁骨到头顶上方留空，按 16:9 定框；1080p 下框宽约 330–470 px 时放大约 2.7–3.7 倍到 1280×720，脸在成片尺度上够清楚。先抽首、中、末帧确认头部运动在框内，再出视频。
- 相邻两人的取景框可以相交，分别准备；贴回原尺寸时同帧裁切不能相交，要分层或在裁切画布上分别合成。

## 2. 绿幕范围

- 用户给的紧贴头部的截图可当绿幕范围，匹配出原片坐标后换算到工作坐标（`mask_regions` 在输出尺寸坐标）。
- **截图顶边切在头发上时**，绿框外露一条旧发梢，Flow 新头可能出现双层头发或硬边。出视频后附对比图提醒，建议上沿扩到头顶以上；用户未指定时默认盖住整头到领口。
- 高清底图作首帧时，先缩到视频尺寸用 ECC 仿射核对（缩放≈1、平移 <0.5 px 才按倍数直接裁同一框）。

## 3. 只交付片段或裁切画布

- **只合某一时间段**：FFmpeg 按帧切出原片该段（`trim=start_frame=N`、`atrim`，高质量 x264，写 709 标签）作源，`target`／`generated_start` 相应改写。
- **在裁切画布上合成、不贴回原尺寸**：同一 `prepare` 配置、`mask_regions=[]` 导出无绿幕裁切作源，`source_size` 设为裁切尺寸，`crop=[0,0,W,H]`，matte 与工作坐标不变。
- **要完整时长**：导出全长无绿幕裁切，从生成段对应帧起设 `target`，逐帧仿射关键帧号整体加偏移。一次编码完成，不首尾拼接，音轨连续；交付前逐帧看换脸接点前后数帧。

## 4. Flow 肤色偏差

- 现象：Flow 返回的皮肤偏绿、少红（实测 G +4～6，R、B −2～7，越亮偏差越大），**未打绿幕的参照帧同样偏**，是生成服务的整体处理。
- `precheck` 的颜色中位数和 `fit_patch` 的固定增益以背景为主：背景环能对到 ±0.1 级，皮肤仍偏 4～7 级，用户一眼看出。**皮肤要单独测**：在参照帧上分区（额头、两颊、下巴、脖子）比较 Flow 与原片。
- 测量用 FFmpeg 显式 BT.709 有限范围解码（`scale=in_color_matrix=bt709:in_range=tv:flags=accurate_rnd+full_chroma_int`）。OpenCV 默认解码的读数可差数级，只看相对趋势。
- 校正：
  1. 先套 `fit_patch` 的背景环增益/偏移；
  2. 在参照帧上取皮肤像素（YCrCb 色度范围 + 亮度下限，限于脸到领口以上的补丁区内，高斯羽化约 3 px），逐通道线性拟合 Flow→原片；
  3. 只对每帧的皮肤软遮罩施加该拟合，背景、头发、眼镜、衣服不动；写成校正后的返回片（解码、编码都用 709 显式矩阵，crf ≤6），再用单位颜色参数合成；
  4. 验证：参照帧各区偏差 ≤2 级，接点前后原片末几帧与 Flow 首几帧皮肤差 ≤3 级（含转头光线变化），背景环不变。
- 这一步是随包脚本以外的本地 NumPy/OpenCV/FFmpeg 处理。按[工具白名单与审批](tool-policy.md)和[身体露肤匹配](skin-match.md)，先向用户说明范围并取得同意再做。
