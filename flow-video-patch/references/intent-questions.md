# 常见含混说法与案例套用

补充 SKILL.md「需求澄清」：何时问、问几个以那里为准。这里给出实际遇到过的短指令、可能的几种交付，以及默认做法。

## 问法

- 选项写成具体交付物（"10 秒 720p 小片段"），不用术语；先给默认理解，用户回答"可以"或未反对就照做，并在回复里写明采用了哪种理解。
- 取景、绿幕、颜色等需要看的，附截图或对比图；能先出截图确认的，确认后再出视频。
- 测得的事实与用户说法不一致（截图取景与视频不同、高清底图只对应首帧、绿幕切到头发）时，照做前说明差异。

## 常见说法

| 说法 | 可能的意思 | 确认／默认 |
|---|---|---|
| "把 N 号截出来" | 截图预览／上传视频／首帧图 | 先出预览截图，确认后出视频 |
| "按这个截取"（附小截图） | 截图是绿幕范围，或只是指认人物 | 紧贴头部→当绿幕范围；含邻人和椅子的宽图→只是指认，绿幕自定并说明 |
| "除了第一帧都打绿幕" | 首帧作 Flow 起始参照 | `context_frames=1` 只留前侧首帧 |
| "截取的图片找我的高清图片" | 首帧图改从高清底图裁 | 先核对底图对应哪一帧；非对应帧提示姿态差异 |
| "从 X 秒到结尾，按刚才的要求" | 沿用取景规则与首帧不打绿幕；绿幕范围是否沿用 | 上次绿幕若切到头发，默认改为盖住整头并说明 |
| "能否合回去" | 只要结论，或直接合成 | 先预检给结论；结论可贴且用户已表示要合时直接合 |
| "合这个截取出来的片段" | 输出只含该时间段，贴回原尺寸 | 原片按帧切出该段再合，一次编码 |
| "未遮挡的小片段和 Flow 片段合并，不用合回原始片段" | 在裁切画布（如 1280×720）上合成 | 用不打绿幕的同几何裁切作底，`crop=[0,0,W,H]` |
| "前面不是有 6 秒吗，合在一起" | 输出完整时长的小片段 | 导出全长无绿幕裁切，从对应帧起合成，不拼接 |
| "颜色要和原片一样"／"主要是皮肤颜色" | 背景环颜色或皮肤颜色 | 分区测色（背景环、额头、两颊、下巴、脖子）后报告偏差，再定调哪里 |

后四种的配置见[裁切小片段与肤色偏差](crop-clip-and-skin-cast.md)。

## 套用已验证路线

确认意图后，说明套用哪条路线、哪些参数需重测：

- 只改口型、保留脸：[局部补丁经验](patch-lessons.md)、[实片经验](field-lessons.md)。
- 观众／背景人物刷口型（小头、固定机位）：[裁切小片段与肤色偏差](crop-clip-and-skin-cast.md)。
- 整头换人或接缝反复失败：[返回片贴合度预检与接缝选位](return-fit-assessment.md)。
- 多人相邻：[多人交界与局部借用](overlap-and-local-donors.md)。
