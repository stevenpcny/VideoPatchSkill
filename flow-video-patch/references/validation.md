# 发行验证

v1.2 加入本地输入协议限制、独占私密输出、符号链接拒绝、配置与像素预算、同步命令超时及拟合参数校验。版权和匿名通用案例延续 v1.1。

发行前检查：技能结构、文档相对链接、参数JSON、文本与文件名隐私扫描、包内哈希，以及从新ZIP独立解压目录执行`python tests/smoke_test.py`。测试使用临时生成的纹理视频、模拟补丁和正弦音频，不使用真实媒体。

测试覆盖上下文和遮挡、运动裁切、嘴部保护、双人多频段融合、显式尾帧重复、null回填、错误拒绝、已知平移拟合、固定颜色拟合、音轨与完整解码。实际本次结果见根目录VALIDATION.json。

本次运行验证平台仅为macOS；Windows与Linux未实跑。合成测试不证明实际生成视频的身份、接缝或逐字口型，也不是无侵权认证。接收者应在自身环境复验，并用授权短片审看。

新增 `python tests/security_test.py` 验证输入协议、特殊文件、文件名选项隔离、符号链接、既有文件防覆盖、权限、失败清理、预算、超时及拟合参数拒绝。完整安全结论见 SECURITY.md；功能测试通过不代表接收电脑的外部依赖已修补。

v1.4 只新增文档：身体露肤匹配参考和必做的融合性与匹配性检查，两个处理脚本和两套测试与 v1.3 字节一致；在 Windows 11（NumPy 2.3、OpenCV 5.0、FFmpeg 7.0）上从新 ZIP 解压目录运行两套测试：功能 6/8、安全 8/10 通过，失败项与 v1.3 ZIP 在同一机器上的结果完全相同，属于既有的 Windows 兼容问题，不是本次文档改动引入的：默认 cp1252 控制台编码（设置 PYTHONUTF8=1 后通过）、固定调色拟合未被采用（test_07）、非管理员无法创建符号链接、Windows 文件占用导致的替换测试失败。这些问题待脚本修订时处理；Windows 上运行前建议设置 PYTHONUTF8=1。

v1.3 只更新白名单、清单外停止／许可证核查／用户批准／使用记录流程及相关说明；两个处理脚本和两套测试保持 v1.2 字节一致。文档、清单、模板、相对链接与隐私扫描一并核对。原有 18 项代码测试不等于验证任意智能体必然遵守指令；没有对所有宿主、模型或操作系统做强制隔离测试。


v1.5.1 修改 `scripts/flow_patch.py` 色彩管线（显式矩阵/范围解码与编码、码流色彩标签、拒绝非 709/601 矩阵），新增 `tests/color_pipeline_test.py`：标签与范围识别、解码无偏、709/601/全范围合成后补丁外 YUV 均值偏差 <0.35 级、两轮合成无漂移、prepare 输出带标签。实片 8K 往返核对 Y/U/V 均值误差 ≤0.01 级；每帧额外约 2 秒（8K）。fit_patch.py 未改，经新 Reader 自动按源矩阵解码。

v1.5 仅更新局部补丁经验、提示词、工作流与验收说明，并新增默认 `pending_visual_review` 的视觉验收记录模板。处理脚本、测试代码、依赖、工具白名单与 v1.4 字节一致。新增文档不赋予自动跟踪、任意逐帧遮罩、10 位/HDR 或自动视觉验收能力；既有 Windows 兼容性及外部依赖安全事项继续保留。本版当前验证结果及历史结果分别见 VALIDATION.json；真实 Flow 生成与正常速度实片视觉验收不在发行测试范围。
