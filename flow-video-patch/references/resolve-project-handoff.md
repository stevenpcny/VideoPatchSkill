# 按需交付可编辑的达芬奇工程

用户希望接手者在达芬奇中保留满意补丁、继续完善局部合成并能调整已有参数时采用此分支。先确认需保留的参数及片段；默认保留所有仍需编辑的补丁分支。普通成片交付不自动进入此流程。

## 交付内容与编辑边界

- 原片和Flow原始返回分别保留，不只提供最终合成视频或带固定alpha的补丁。
- 每个补丁或人物建立独立、清楚命名的Fusion分支：素材/帧映射 → 位置/尺寸/跟踪 → 颜色/清晰度 → 遮罩/羽化 → Merge → 输出。保留先后遮挡与原音轨；可用旁路或Blend=0对照。
- 已满意部分优先保留原节点和默认参数，接手者只修改问题分支。有意固化的部分须逐项说明并经用户接受，不能为了方便自动改成交付底片。
- 保留遮罩形状、控制点或逐帧/关键帧信息；遮罩视频仅能保留像素效果，不能称为可编辑控制点。已有固定颜色修正、透明度、过渡及跟踪也需映射成原生参数/曲线。
- Flow生成画面本身是像素素材，不能恢复生成模型内部参数；可编辑的是后续合成结构。只剩最终MP4时，先报告缺失素材/参数及重建范围。
- 原流程的数学羽化、非线性变形、多频段融合、光流或特殊调色未必能与原生节点一一对应。记录精确转换、近似转换和固化的项目；近似转换不能宣称默认画面无损一致。

## 工具与可执行路径

继续遵守[工具规则](tool-policy.md)。本指南不把Resolve、Fusion Studio或任何MCP加入默认白名单；只复用匹配版本/用途的已完成核查和用户授权，否则完成对应扩展步骤。无须重新索取本会话已明确覆盖的授权。不要安装、替换软件或修改全局MCP配置作为本分支的隐含动作。

免费Resolve的内部Lua控制台曾通过单帧节点构建、参数读写、连接读回及工程导出验证；这只是一个实际环境的能力证据，不是所有版本保证，也没有证明视频跟踪、视觉一致性、重新导入或跨机移交。先读取当前版本并做最小能力检查。

1. 优先使用已可用、已核查的接口。内部控制台可以用全局 `resolve` 及 `resolve:Fusion()`；外部桥 `scriptapp("Resolve")` / `scriptapp("Fusion")` 必须实际连接后才能使用。外部失败不代表内部不可用。
2. `hensenx/fusion-mcp` 的仓库目标是独立Fusion Studio；其底层外部连接在该次免费Resolve环境未连通，不把“免费Render Node”理解为免费Resolve支持。内部脚本成功不等于MCP成功。未来若采用插件，重新检查源码、依赖、版本与实际连接，不把此指南当作安装或使用授权。
3. 若无法自动操作桌面，生成任务专用Lua脚本，让用户在Workspace → Console选择Lua并执行一条 `dofile` 命令。每次执行前说明是否新建工程、会修改什么、完成标志是什么；命令中的路径来自实际任务，不能照搬案例。
4. 新建独立工程并保留原工程。脚本用 `pcall` 捕获错误，用 `Lock` / `StartUndo` / `EndUndo` / `Unlock` 保证异常解锁；禁止删除或覆盖用户已有工程。错误信息应指出失败节点/参数。
5. 部分内部环境没有Lua `io`，不要把写报告文件作为接口工作的前提。先 `print` 输出状态；按实际可用的原生工程/合成导出API保存文件。未核查环境不要调用缺失接口或要求关闭安全限制。

## 节点构建的实测注意事项

- UI中的“Custom Tool”内部RegID为 `Custom`，不是 `CustomTool`。以注册表、GetInputList和实际读回为准，不凭显示名猜内部字段。
- 避免创建节点时隐式连线：创建前 `comp:SetActiveTool(nil)`，按当前API显式指定AddTool参数；所有连接检查返回值，再以 `GetConnectedOutput():GetTool()` 读回真实上游。
- 图片可用Loader；视频优先用媒体池/MediaIn，或经验证的图片序列。不要假定Loader能解码任意视频。素材路径在赋值后可能改变节点显示名，后续按明确句柄或可靠标识访问。
- 位置可用Transform；原生EllipseMask/Polygon等保留遮罩与SoftEdge；Merge的Background接原片、Foreground接补丁、EffectMask接遮罩。
- 需要固定RGB gain/offset时，可用Custom的 `NumberIn1..6`、`RedExpression="r1*n1+n4"`、`GreenExpression="g1*n2+n5"`、`BlueExpression="b1*n3+n6"`。先核对RGB/BGR顺序、像素范围、输入色彩空间、alpha和原流程运算空间，不能直接复制其他镜头的系数。
- Fusion坐标通常归一化且Y轴方向与图像像素坐标不同，逐项验证裁切偏移、尺寸、像素宽高比和坐标方向。时间基准、 `[start,end)` 与含尾帧转换必须显式处理。
- 单张静帧默认时间线时长不是视频长度证明。Loader的GlobalIn/Out、Hold/Extend和实际帧范围须覆盖测试区间；不能因时间线有数秒就声称数秒合成通过。

## 验证顺序与证据

实现前用[交付记录模板](../assets/resolve-handoff-template.json)定义本次完成标准，先短样本再扩展。

1. **结构与读写**：实际列出节点，核对原片/Flow路径及连接；将目标参数改成另一个值并读回，再恢复并核对。不能只检查SetInput没报错。
2. **视觉响应**：渲染或预览“补丁关/开”及关键参数改变后的画面，确认影响区域和预期一致。参数数值可写不等于渲染有效。
3. **完整视频**：映射所有生成帧、原片帧及关键帧；检查首/中/尾、问题窗口与所有修补帧，完成最终编码文件正常速度播放。保留原声口型、接缝、遮挡及身份范围要求，按[视觉验收](verification.md)记录。
4. **默认外观保留**：与原先已满意的合成比较，记录差异；未达到默认外观要求则标为重建候选，不能宣称已保留成功效果。
5. **保存重开**：保存项目，导出 `.drp` 和按需 `.comp`，实际重新导入/重开，核对素材、节点、曲线、参数和画面。只检查ZIP或文本结构不能替代达芬奇重开。
6. **移交与迁移**：把包放入另一根目录，修正/重链接媒体池素材及所有Loader路径，再从包内打开验证。尽可能在目标版本/电脑测试；没有执行的项保持 `not_run`。

## 工程必须连同补丁素材交付

`.drp`保存工程结构和素材引用，不内嵌视频/图片；`.comp`保存节点结构，也不内嵌Loader引用的媒体。不要回答“导出了工程就已经包含补丁”。

用户要求完整交付时，默认提供一个可搬走的文件夹或ZIP，包含：

```text
handoff/
  project.drp
  comps/                    # 需要时的独立合成
  media/original/           # 原片或经说明的源片段
  media/flow/               # Flow原始返回
  media/mattes/             # 仍被引用的遮罩/序列
  data/                     # 帧映射、跟踪、配置等必需数据
  relink.lua                # 需要时生成的任务专用路径重定位脚本
  handoff.json              # 文件清单、相对路径、SHA256及验证状态
  使用说明.md
```

- 不随包复制达芬奇程序、插件安装包或不必要缓存。重定位脚本只能操作明确匹配的交付工程，不能修改其他工程或调用网络。
- 优先用媒体池管理素材；Loader若必须保留，记录并核查每一个依赖。相对路径/PathMap须在真实移目录测试后才能称可搬移；媒体池重链接不自动修复Loader。
- 可用达芬奇原生 `.dra` 归档，但须实际核对所有媒体，特别是Fusion Loader、外部遮罩与序列是否被收集；漏项另行复制并重定位。不能仅凭导出返回true宣称已包含全部素材。
- 按帧序列核对帧数/编号连续性，逐文件记录SHA256。复制包内媒体后，确认工程不再依赖原工作目录；只能在本机原路径打开时标为迁移待验。
- 区分“素材已随包提供”“原生节点可编辑”“画面已验收”“跨机已验证”，分别报告。技能发行ZIP本身不携带用户素材；实际工程交付ZIP才包含原片和补丁。
