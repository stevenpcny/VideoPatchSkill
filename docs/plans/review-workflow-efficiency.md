# 遮罩、接缝审批与效率对照试验

状态：待实片试验；本文未声明效率收益已实现。

## 目标与范围

减少原片检查、制作遮罩、返回片检查、贴回、审片及渲染中的返工。使用已有原片、返回片和旧版本，不把额外生成作为前提。典型输入为720p/1080p、24/30fps、少于30秒、1–3个补丁；不是处理能力上限。

## 试验设计

选一段有明确历史颜色、接缝或遮挡反馈且保留旧版本的镜头做首轮；再选复杂背景、整人运动镜头复验。只在任务本地记录实际素材与帧号。

1. 核对原片规格、问题区间、首尾和最大运动，区分裁切画布、生成遮罩和贴回遮罩。
2. 正式遮罩制作前展示适用候选；返回片预检后展示2–3个实质不同的可行接缝方案。实际帧标出满替换区、羽化带、保留区与遮挡关系，给首选和风险；不凑不可行候选。
3. 按用户审批范围执行；先做高风险短窗口，再做完整检查片。提供原片/成片并排及接缝图；近景1080p、中远景4K，注明放大来源，原像素细节另作对照。
4. 完整检查片通过且最终导出获批准后导出交付文件，复核最终编码、完整动态边缘及原声口型。静态审批或短片通过不代替最终视觉验收。
5. 记录每次反馈对应的版本、时空位置、原因假设、修改和复验范围。

渲染对照：同一批准参数与编码设置，比较NumPy/Rust耗时和输出一致性，记录机器、线程、缓存状态及重复次数，不将机器差异当作内核收益。
流程对照：尽可能使用同一镜头与相同输入，记录主动操作、机器计算、用户等待三类时间及总历时（并行时间不重复相加）、完整渲染次数、返工次数、人工确认轮次、首次发现问题的阶段。历史计时缺失就标未知；新流程重走旧镜头受已知问题影响，结果只能作为试点，需后续新镜头验证。

## 建议完成标准与回退

- 已知颜色/遮挡/羽化/接缝问题在完整导出前暴露，批准后不因同一问题重复完整导出；最终视觉要求不降低。
- 试点目标为主动处理时间下降25%、完整渲染至少减少一次；仅在基线足够时计算，不是承诺。
- 方案不成立时保留旧素材/输出/参数，回到候选选择或建议重新生成；不扩大羽化掩盖问题。
- 本试验结果及真实反馈进入任务本地记录；验证过的通用经验再更新技能，个例坐标与私人素材不进入发行包。
